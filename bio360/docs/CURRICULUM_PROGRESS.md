# Progresso curricular local

O `CurriculumProgressManager` relaciona:

```text
manifesto do módulo
        +
curriculum.units[]
        +
evidências locais
        =
painel por unidade curricular
```

## Importante

O percentual exibido é um índice interno da plataforma.

Ele:

- não substitui avaliação docente;
- não é uma nota oficial;
- não representa conclusão formal da unidade curricular.

Serve para:

- visualizar uso dos laboratórios;
- localizar áreas ainda pouco exploradas;
- acompanhar evidências;
- organizar portfólio.
