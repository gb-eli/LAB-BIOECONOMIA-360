# Início do pacote G4 de assets

A v0.10.0 começa a substituir elementos puramente procedurais por GLBs locais com variantes.

## Assets

### Tanque industrial
- ECO
- HIGH

### Quiosque de mercado
- ECO
- HIGH

## Regra

O laboratório utiliza um ID lógico.

```text
shared-industrial-tank
shared-market-kiosk
```

O AssetManager escolhe a variante conforme o perfil gráfico.

Isso permite aumentar fidelidade sem alterar a lógica pedagógica.
