# Dependências externas

## Three.js

- Pacote: `three`
- Versão fixada: `0.185.1`
- Licença: MIT
- Carregamento: jsDelivr por import map
- Motivo: renderização WebGL, cena 3D e suporte a glTF.

## Política

A versão é fixada para evitar mudanças inesperadas.

Em uma fase futura, a biblioteca poderá ser vendorizada no próprio repositório se for desejável remover a dependência de CDN.
