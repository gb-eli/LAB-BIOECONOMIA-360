# Comparator V3

Além dos pilares e scores, a comparação agora mostra:

- decisões de eventos;
- branches compartilhadas/exclusivas;
- correções pós-ativação;
- consequências;
- resultado financeiro;
- margem financeira;
- completude/confiança.

Isso ajuda a comparar o caminho profissional, e não apenas o score final.
