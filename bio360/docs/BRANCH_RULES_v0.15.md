# Ramificações iniciais

## Seca → solução corretiva

Se o aluno escolher manter o plano sem adaptação:

```text
+ Soluções Sustentáveis obrigatória
```

A etapa só termina após `sustainable-solution-plan`.

## Centralização → reparação

Se o conflito de governança for respondido por centralização:

```text
+ Plano corretivo de governança obrigatório
```

Conclusão por `governance-remediation`.

## Lote sem ajuste → recuperação

Se a organização vender o lote sem correção:

```text
+ Recuperação de qualidade obrigatória
```

Conclusão por `quality-remediation`.

## Parceria com turismo

Se a estratégia escolhida for parceria turística:

```text
Turismo:
opcional → obrigatório
```

## Rastreabilidade

Se a rastreabilidade for implantada:

```text
+ Posicionamento premium rastreável [bônus]
```

Conclusão por `premium-market-route`.
