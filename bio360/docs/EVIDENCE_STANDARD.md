# Evidências de aprendizagem — v0.6.0

Cada missão pode gerar um registro local com:

```json
{
  "moduleId": "lab-producao-vegetal",
  "scenarioId": "periodo-seco",
  "input": {},
  "indicators": {},
  "evaluation": {},
  "reflection": "..."
}
```

## Objetivo

A avaliação deixa de ser somente:

```text
clicou certo / clicou errado
```

e passa a registrar:

- cenário;
- decisões;
- indicadores;
- metas atendidas;
- justificativa;
- data.

## Privacidade

Nesta versão, os registros são locais no navegador.

Nenhum dado é enviado para servidor.

## Exportação

O Dashboard permite exportar todas as evidências em JSON.
