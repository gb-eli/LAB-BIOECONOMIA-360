# Benchmark Bundle G6 — v0.32

Objetivo principal:

```text
rodar no celular
      ↓
exportar pacote
      ↓
abrir em outro dispositivo
      ↓
importar
      ↓
analisar benchmark/regressão
```

Formato:

```text
JSON
```

Conteúdo:

- versão;
- perfil do dispositivo;
- telemetria;
- baselines;
- budgets;
- progresso guiado;
- metadados visuais.

Existe uma opção separada:

```text
Exportar + imagens
```

Nesse caso as miniaturas JPEG locais também entram no JSON.
