# Clonagem de estratégia

A clonagem foi criada para experimentos comparativos.

Exemplo:

```text
Produto Territorial
      │
      ├── Sessão A
      │     irrigação eficiente
      │     rastreabilidade
      │     preço premium
      │
      └── Sessão B
            redução de escala
            canal turístico
            preço competitivo
```

Cada sessão recebe:

- `sessionId` diferente;
- `productId` diferente;
- Projeto Integrador diferente.

A identidade textual pode ser semelhante, mas os dados permanecem isolados.
