# Asset Composition G8

Nova biblioteca:

```text
js/graphics/immersive-asset-composer-g8.js
```

Ela utiliza o AssetManager já existente.

Não há fetch direto de modelos.

Os modelos continuam:
- carregados sob demanda;
- escolhidos conforme perfil gráfico;
- liberados pelo AssetScope.

O compositor posiciona poucos objetos reconhecíveis em pontos estratégicos em vez de repetir geometria em toda a cena.
