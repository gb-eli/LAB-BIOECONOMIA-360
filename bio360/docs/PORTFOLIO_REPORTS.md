# Portfólio e relatórios — v0.10.0

A plataforma pode gerar relatórios sem servidor.

## Projeto Integrador

O usuário pode:

- exportar JSON;
- exportar relatório HTML;
- abrir versão de impressão;
- usar a opção do navegador "Salvar como PDF".

## Relatório do projeto

Inclui:

- território;
- produção;
- processamento;
- circularidade;
- turismo;
- viabilidade;
- evidências associadas;
- transferências LabContext;
- progresso interno.

## Portfólio geral

O módulo Portfólio agrega:

- Projetos Integradores;
- evidências;
- transferências;
- exportação HTML.

## Importante

O relatório é didático.

Indicadores da plataforma não representam nota oficial.
