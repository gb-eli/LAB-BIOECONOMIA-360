# Environment Pack compartilhado

Arquivo:

```text
js/graphics/environment-pack.js
```

Elementos iniciais:

- rochas;
- arbustos;
- pallets;
- compostagem;
- biodigestor simplificado;
- sprinkler;
- gotas de água;
- plantas por tipo.

O objetivo é aumentar a ambientação sem duplicar código entre laboratórios.

## Relação com Scene Kit

```text
Scene Kit
→ elementos estruturais

Environment Pack
→ elementos ambientais, produtivos e acessórios
```

Ambos não contêm regras pedagógicas.
