# Integração entre laboratórios

A plataforma começa a formar uma rede de experiências.

## Fluxo atual

```text
Produção Animal
   ├── resíduos → Biodigestor
   └── resíduos → Economia Circular

Agroindústria
   └── resíduos/subprodutos → Economia Circular

Economia Circular
   ├── biodigestão → Biodigestor
   ├── origem industrial → Agroindústria
   └── origem pecuária → Produção Animal
```

A integração atual é conceitual e navegacional.

Fases futuras poderão transferir um cenário ou valores entre laboratórios através de um `LabContext`.
