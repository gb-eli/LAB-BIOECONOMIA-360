# Comparador MultiLab

Novo módulo:

```text
#/module/comparador-multilab
```

Compara duas sessões.

## Pilares

- Governança
- Produção
- Circularidade
- Mercado
- Resiliência
- Financeiro

## Percurso

Também compara:

- score final;
- eventos;
- ramificações;
- consequências;
- evidências;
- progresso do Projeto Integrador.

## Insight

O comparador não declara automaticamente que "mais ramificações" é pior.

Uma ramificação pode representar:

- correção necessária;
- rota bônus;
- oportunidade premium;
- exploração adicional.

Por isso os insights combinam score e estrutura do percurso.
