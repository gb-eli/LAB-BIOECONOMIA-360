# Relatório de Regressão Gráfica

`GraphicsRegressionReportBuilder` exporta um HTML independente com:

- cobertura;
- PASS/WARN/FAIL;
- baseline anterior;
- hardware comparável ou não confirmado;
- maiores regressões;
- recomendações;
- quantidade de capturas visuais locais.

É uma síntese dos dados locais e não substitui teste manual em dispositivo real.
