# Interactive Environment G12 — v0.41

O fluxo agora é:

```text
Caminhar
  ↓
aproximar
  ↓
Interagir
  ↓
ação visual no ambiente
```

Exemplos:

```text
água
→ fluxo visível

agroindústria
→ estação anima

efluente
→ aeração

portal
→ abre/fecha
```

## Estado

Algumas ações usam toggle:

```text
ligar
↔
desligar
```

Outras são temporárias:

```text
ativar
→ animação por alguns segundos
→ desligar
```

## Importante

A mudança visual é uma representação didática.

Ela não substitui automaticamente:
- indicador;
- resultado da missão;
- evidência curricular;
- consequência MultiLab.

Quando existe lógica curricular real, ela continua sendo chamada separadamente.
