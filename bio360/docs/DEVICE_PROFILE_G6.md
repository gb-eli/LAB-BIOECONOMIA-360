# Perfil de Dispositivo G6

O perfil é local.

Exemplos de campos:

```text
classe
deviceMemory
hardwareConcurrency
screen width/height
DPR
touch
platform
```

O usuário pode atribuir um nome amigável.

Exemplo:

```text
Moto G34
PC Sala 2
Notebook Professor
```

O ID é aleatório e local, criado apenas para relacionar sessões do mesmo navegador/dispositivo.
