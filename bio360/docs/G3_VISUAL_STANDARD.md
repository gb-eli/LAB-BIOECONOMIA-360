# Padrão visual G3

G3 representa alta fidelidade intermediária, ainda otimizada para web.

## Requisitos

- iluminação mais coerente;
- atmosfera;
- materiais mais diferenciados;
- objetos secundários;
- detalhes ambientais;
- sinalização;
- elementos de escala;
- LOD;
- qualidade adaptativa;
- fallback funcional.

## Aplicado nesta versão

### Território Bioeconômico
- atmosfera;
- névoa exponencial;
- sol visual;
- nuvens;
- rochas;
- ambientação reforçada.

### Agroindústria
- iluminação de teto;
- tubulações;
- marcação de segurança;
- névoa controlada;
- aspecto mais técnico.
