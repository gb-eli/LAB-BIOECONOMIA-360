# Regras de desempenho — v0.16

## Governança

Se:

```text
governança < 65
OU
equidade < 60
```

abre reforço de governança.

Se houver centralização durante conflito, mas os indicadores estruturais forem excepcionalmente altos:

```text
governança >= 88
equidade >= 82
transparência >= 85
```

a etapa formal de reparação pode ser dispensada.
