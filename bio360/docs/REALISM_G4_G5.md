# Realismo visual G4/G5 — início

A v0.19 abre a trilha de realismo otimizado.

## Princípio

O objetivo não é transformar o projeto em um jogo AAA.

O objetivo é:

```text
escala convincente
+ materiais melhores
+ iluminação coerente
+ detalhes identificáveis
+ panorama 360
+ desempenho adaptativo
```

## Realism Kit

`js/graphics/realism-kit.js`

Oferece:

- texturas procedurais via CanvasTexture;
- materiais para solo;
- concreto;
- estrada;
- sky dome;
- tone mapping;
- exposição;
- configuração de sombras.

## Território

Recebeu:

- sky dome;
- solo texturizado;
- estrada texturizada;
- sombra conforme perfil;
- exposição adaptativa.

## Agroindústria

Recebeu:

- piso texturizado;
- parede texturizada;
- luz/sombra adaptativa;
- ACES tone mapping.
