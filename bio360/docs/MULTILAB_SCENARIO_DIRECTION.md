# Direção para cenários multi-laboratório

A v0.12.0 estabelece a infraestrutura para uma missão que atravessa vários laboratórios.

Exemplo futuro:

```text
Produto regional
  → diagnóstico territorial
  → modelo associativo
  → produção
  → processamento
  → circularidade
  → marketing
  → precificação
  → financeiro
  → projeto final
```

O próximo passo é declarar uma missão mestra em JSON com:

- etapas obrigatórias;
- rotas opcionais;
- critérios de conclusão;
- evidências mínimas;
- produto comum;
- regras de transferência.
