# Benchmark Guiado G6 — v0.31

## Teste rápido

```text
8 cenas
×
ECO + ULTRA
=
16 passos
```

## Teste completo

```text
8 cenas
×
ECO + BALANCEADO + ALTO + ULTRA
=
32 passos
```

Ao iniciar um passo:

1. o perfil correto é aplicado;
2. o laboratório é aberto;
3. um banner exibe o cronômetro;
4. o usuário explora a cena;
5. ao sair, a telemetria é encerrada;
6. o passo é validado.

Se o tempo medido for muito curto, o passo fica como:

```text
tempo insuficiente
```

e deve ser repetido.
