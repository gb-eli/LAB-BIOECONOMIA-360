# Auditoria visual v0.35

## Regras aplicadas

1. Um laboratório 3D deve abrir mostrando o 3D.
2. Uma experiência 360 deve abrir mostrando o panorama.
3. Painéis técnicos ficam recolhidos.
4. Relatórios ficam fora da exploração.
5. Qualidade gráfica não precisa ocupar o primeiro plano.
6. Hotspots abrem contexto sob demanda.
7. Fallback 2D continua disponível, mas não recebe layout de tela inteira forçado.
8. “Experiência 3D” só é usada para ambientes cuja exploração espacial é parte central.
9. “Simulação 3D” é usada quando o 3D ajuda a decisão, mas não constitui uma experiência imersiva completa.
