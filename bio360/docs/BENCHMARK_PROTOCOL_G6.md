# Protocolo de Benchmark G6

Para comparar perfis de modo razoável:

1. usar o mesmo dispositivo;
2. usar o mesmo navegador;
3. abrir o mesmo laboratório;
4. fazer o mesmo percurso;
5. permanecer aproximadamente 20–30 segundos;
6. sair da cena para gravar o resumo;
7. repetir em outro perfil.

Comparações úteis:

```text
ECO × ULTRA
BALANCEADO × ALTO
```

Observar conjuntamente:

- FPS médio;
- FPS mínimo;
- P95;
- draw calls;
- triângulos;
- texturas;
- DPR.

O benchmark no navegador desktop não substitui teste em celular.
