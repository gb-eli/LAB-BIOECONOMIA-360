# Cadeia integrada por LabContext — v0.10

Novos fluxos:

```text
Território
├──→ Produção Vegetal
└──→ Produção Animal

Produção Vegetal
└──→ Agroindústria

Produção Animal
├──→ Agroindústria
├──→ Biodigestor
└──→ Economia Circular

Agroindústria
└──→ Economia Circular
```

## Território → Produção

O diagnóstico envia índices didáticos de:

- água;
- conservação;
- mercado;
- participação local;
- acesso a processamento;
- infraestrutura de resíduos.

## Produção → Agroindústria

O lote contém:

- origem;
- produto;
- índice de oferta;
- umidade;
- qualidade de manejo;
- requisitos específicos.

A Agroindústria aplica o lote sem alterar o motor de fluxo das estações.
