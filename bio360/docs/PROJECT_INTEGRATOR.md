# Projeto Integrador de Bioeconomia

O Projeto Integrador conecta os laboratórios e ferramentas em um produto cumulativo.

## Eixos

1. Território
2. Produção
3. Processamento
4. Circularidade
5. Turismo e território
6. Viabilidade

## Fontes de dados

O projeto pode receber:

- dados inseridos manualmente;
- LabContext;
- evidências;
- resultado da ferramenta Gestão Financeira.

## Estrutura

```text
Projeto
├── território
├── produção
├── processamento
├── circularidade
├── turismo
├── viabilidade
├── evidências
└── transferências
```

## Objetivo pedagógico

O aluno deve conseguir construir uma proposta coerente de bioeconomia em que:

```text
recurso
→ produção
→ transformação
→ valor
→ mercado/turismo
→ resíduos
→ circularidade
→ viabilidade
```

sejam tratados como partes do mesmo sistema.
