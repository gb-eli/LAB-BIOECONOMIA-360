# Flow Kit

Arquivo:

```text
js/graphics/flow-kit.js
```

Objetivo:

reutilizar representações de fluxo em diferentes laboratórios.

Recursos iniciais:

- seta 3D;
- tubo/linha de fluxo;
- partículas;
- animação entre origem e destino.

Aplicações futuras:

- biomassa;
- resíduos;
- água;
- energia;
- produto;
- dinheiro;
- logística;
- cadeias produtivas.
