# Walk Mode G10 — v0.39

O modo Caminhar existe para reduzir a sensação de “modelo 3D girando”.

```text
Orbit
→ observar a cena inteira

Cinema
→ apresentação automática

Caminhar
→ explorar na altura humana
```

## Celular

Joystick:
- esquerda da tela.

Olhar:
- arraste sobre o ambiente.

## Desktop

```text
WASD
ou
setas
```

Arrastar:
- olhar.

Esc:
- sair.

## Colisão

A v0.39 usa:

```text
bounds retangulares
+
blockers 2D
```

Não há física rígida nem colisão mesh a mesh.

Isso mantém o custo baixo e é suficiente para impedir atravessamentos mais evidentes.
