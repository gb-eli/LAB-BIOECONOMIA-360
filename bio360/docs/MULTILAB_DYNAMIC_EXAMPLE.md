# Exemplo de consequência acumulada

Suponha que o aluno escolha:

1. reduzir a escala durante a seca;
2. realizar assembleia transparente;
3. reprocessar o lote;
4. implantar rastreabilidade;
5. diversificar canais.

O mesmo produto pode chegar ao financeiro com:

```text
Oferta produtiva ........ reduzida
Confiança de mercado .... aumentada
Qualidade industrial .... recuperada
Valor sustentável ....... aumentado
Custo variável .......... aumentado
Custo fixo .............. aumentado
Volume comercial ........ parcialmente recuperado
```

Assim o resultado final não depende somente das escolhas feitas na tela financeira.

Ele carrega decisões das etapas anteriores.
