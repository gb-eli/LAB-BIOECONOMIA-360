# Detail Layer G9 — v0.38

Objetivo:

```text
reduzir aparência de maquete
sem transformar a cena em um arquivo pesado
```

A camada G9 trabalha com:

- microgeometria;
- materiais PBR;
- objetos repetidos instanciados;
- bordas menos vazias;
- solo menos uniforme;
- pequenas estruturas;
- fog leve.

## Perfis

ECO:
- menor densidade;
- fog ligeiramente mais forte.

BALANCEADO:
- densidade intermediária.

ALTO/ULTRA:
- mais detalhes visíveis;
- maior distância visual.

## Importante

Os detalhes continuam procedurais e leves.

Eles melhoram materialidade e composição, mas não são substitutos de um pacote de modelos fotorealistas.
