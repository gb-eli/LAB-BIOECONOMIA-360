# Cadeia Produtiva Integrada

A plataforma passa a reconhecer a jornada de um produto como um conjunto de contextos.

Etapas:

1. Território
2. Governança
3. Produção
4. Processamento
5. Circularidade
6. Marketing
7. Turismo
8. Precificação
9. Financeiro

O `IntegratedJourneyManager` procura o contexto mais recente para cada etapa.

A Cadeia Produtiva Integrada mostra:

- etapas disponíveis;
- resumo de cada etapa;
- percentual de completude;
- produto percorrendo a cadeia em 3D;
- links para completar etapas ausentes.

A síntese pode ser enviada ao Projeto Integrador.
