# Som ambiente

Novo núcleo:

```text
js/core/ambient-audio-manager.js
```

Áudios:

```text
assets/shared/audio/territory-ambient.mp3
assets/shared/audio/agroindustry-ambient.mp3
```

Os áudios são locais e sintetizados para a plataforma.

Não existe autoplay obrigatório.

O usuário precisa tocar em:

```text
Ativar som ambiente
```

Isso respeita as políticas de áudio dos navegadores móveis.

O som é pausado/liberado ao sair da experiência.
