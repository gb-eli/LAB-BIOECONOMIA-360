# Roteirização Turística

O laboratório trabalha com:

- seleção de atrativos;
- ordem das paradas;
- tempo de visita;
- deslocamento relativo;
- limite de paradas;
- experiência;
- logística;
- sustentabilidade;
- benefício local.

## Cenários

- roteiro de meio dia;
- roteiro de dia completo;
- roteiro de base comunitária.

## Regra pedagógica

O objetivo não é apenas incluir o maior número possível de atrações.

O estudante deve justificar:

- por que selecionou os pontos;
- por que usou determinada ordem;
- como respeitou o tempo;
- como beneficiou o território.
