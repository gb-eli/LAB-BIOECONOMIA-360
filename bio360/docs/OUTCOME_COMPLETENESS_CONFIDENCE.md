# Completude e Confiança do Desfecho

Os seis pilares são:

- Governança;
- Produção;
- Circularidade;
- Mercado;
- Resiliência;
- Financeiro.

Cada pilar informa se é:

```text
observed
ou
estimated
```

Um valor estimado é usado somente para manter a projeção numérica funcionando.
Ele não é contado como dado observado.

## Completude

```text
pilares observados / 6
```

## Confiança

- Alta: >= 84%
- Média: >= 50%
- Baixa: < 50%

## Status

```text
missão concluída + 100% observado
→ Desfecho final

qualquer outro caso
→ Desfecho projetado
```
