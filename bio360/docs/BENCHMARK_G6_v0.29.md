# Benchmark G6 Automático

Novo:

```text
js/core/graphics-benchmark-manager.js
```

Matriz inicial:

```text
8 cenas G6 × 4 perfis = 32 pares
```

Para cada par, o sistema usa a medição mais recente da versão atual.

Resultados:

- cobertura;
- PASS;
- WARN;
- FAIL;
- índice de custo;
- ranking.

O Benchmark não abre laboratórios sozinho.
Ele consolida automaticamente as medições reais geradas durante o uso da plataforma.

Isso evita um benchmark artificial que não represente a interação real.
